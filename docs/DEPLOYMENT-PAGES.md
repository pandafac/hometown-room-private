# 部署记录与安全边界

> 当前状态：公开部署已于 2026-11-09 下线。
>
> 历史仓库已设为私有，`gh-pages` 分支已删除；不再提供可访问的公开链接。

## 下架原因

Demo 5.0 是浏览器端单文件应用。只要页面可以被访问，访问者就可以查看并提取其中的前端代码、数据结构和构建时配置。此前使用的临时公开授权已经结束，因此不能继续依靠公开 GitHub Pages 提供访问。

## 当前可用交付

- 本地完整版：`npm run dev`
- 单文件演示：`outputs/会客厅Demo 5.0.html`
- 可发送副本：`deliverables/会客厅Demo 5.0.html`
- 受控静态部署包：`deploy/`

`deploy/index.html` 现在从同目录的 `chunks/` 加载版本化内容包，不再请求旧 GitHub 仓库、jsDelivr 或第三方代理。

## 重新上线的前提

1. 模型密钥必须移到服务端代理，不能继续注入浏览器端构建产物。
2. 托管平台必须提供登录、密码或其他真实访问控制；“随机长链接”只降低发现概率，不能防止拿到链接的人查看源码。
3. 上传前检查 `.env.local`、构建产物、截图和文档中是否包含凭据。
4. 上线后验证未登录访问会被拦截，而不是只显示一个前端密码框。
